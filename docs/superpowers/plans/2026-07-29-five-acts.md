# Five Acts, Full Trees, Real Score -- Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand the slice to all five Diablo 2 acts (35 areas), grow both classes to
their canon 30-skill trees, and replace the humming drone with a per-act procedural
score -- per `docs/superpowers/specs/2026-07-29-five-acts-design.md` (the spec; read it
first, it carries the tables this plan references).

**Architecture:** Pure data growth over the existing engines wherever possible (areas,
monsters, figures, terrains, NPCs, skills are all data files feeding shared bakers and
schedulers); new engine mechanics are limited to ground hazards, a turret pet, chain/
beam projectiles, buff hooks, and a mood-table music engine with an offline-render seam.

**Tech Stack:** Vanilla ES modules, no dependencies, no external assets. `node build.js`
bundles to a single `diablo.html`. Verification drives the BUILT file in Chrome via
chrome-devtools MCP.

## Global Constraints

- Zero asset files: art and audio stay procedural (spec charter).
- Narrative comments, no emoji, surgical diffs; match the codebase voice.
- After every task: `node build.js`, verify against the built `diablo.html`, console
  must stay clean, then commit (Conventional Commits, style of `git log`).
- Debug hooks available on the page: `__forceLoad()`, `__newGame(cls)`, `__continue()`,
  `__step(dt)`, `__render()`, `__enter(areaId)`, `__g`, `__audio`. Backgrounded tabs
  throttle rAF -- drive everything through these, never wait on animation.
- Budgets (spec section 5): cold bake to title <= 1.6 s; frame p95 <= 16.67 ms in the
  heaviest scene; single-file bundle, file:// runnable.
- Existing save files (v1) must keep loading (spec section 4).
- Skill rank cap stays 20; skill req tiers are 1/6/12/18/24/30; LEVEL_CAP moves to 50.
- Worker discipline: WRITE files, do not plan. Read the spec section named in your
  task plus the files you touch before editing. Never `git push`.

- [ ] **Step 2: Voice primitives.** Add alongside `mnote`/`mthump`, all taking `(ctx, bus,

```js
// A plucked string: a millisecond of noise into a feedback delay whose loop
// carries a lowpass, so each pass around the loop dulls -- Karplus-Strong.
// loopHz sets pitch (delay = 1/loopHz), brightness the loop filter cutoff.
function pluck(ctx, bus, when, freq, o = {}) {
  const dur = o.dur || 1.2;
  const burst = ctx.createBufferSource();
  burst.buffer = noiseBufferFor(ctx);          // see step 3
  const bg = ctx.createGain();
  bg.gain.setValueAtTime(1, when);
  bg.gain.setValueAtTime(0, when + 1 / freq);  // one period of noise seeds the loop
  const delay = ctx.createDelay(1);
  delay.delayTime.value = 1 / freq;
  const damp = ctx.createBiquadFilter();
  damp.type = 'lowpass';
  damp.frequency.value = o.brightness || 2600;
  const fb = ctx.createGain();
  fb.gain.value = o.sustain ?? 0.985;          // loop gain < 1 or it rings forever
  const out = ctx.createGain();
  out.gain.setValueAtTime(o.gain ?? 0.16, when);
  out.gain.exponentialRampToValueAtTime(0.0001, when + dur);
  burst.connect(bg); bg.connect(delay);
  delay.connect(damp); damp.connect(fb); fb.connect(delay);   // the loop
  delay.connect(out); out.connect(bus);
  burst.start(when); burst.stop(when + 0.05);
  // Feedback loops outlive their sources; schedule the output gain to zero and
  // let the graph be collected when the bus goes.
}
```

  plus `pad` (3 detuned saws -> lowpass, attack >= 0.4), `bell` (two sines at ratio
  1:2.76, exponential decay >= 2 s), `shaker` (bandpassed noise, dur <= 0.08), `wind`
  (looping noise source through a lowpass whose frequency an LFO sweeps 200-900 Hz,
  gain <= 0.05, **duration-bounded per bar** -- scheduled per-bar like every other
  voice, never free-running, so nothing can outlive a mode change and hum).

```js
const keys = ['a1','a2','a3','a4','a5']
  .flatMap(a => ['town','field','dungeon'].map(k => `${a}.${k}`));
const out = {};
for (const key of keys) {
  const buf = await __audio.renderMood(key, 10);
  const d = buf.getChannelData(0);
  let peak = 0, sum = 0;
  const sub = [];               // sub-60 Hz proxy: 1024-sample block means
  for (let i = 0; i < d.length; i++) {
    const v = Math.abs(d[i]); peak = Math.max(peak, v); sum += v * v;
    if (i % 1024 === 0) sub.push(d[i]);
  }
  // Drone regression: a constant hum keeps long-window mean magnitude high.
  let drift = 0;
  for (let i = 256; i < sub.length; i++)
    drift += Math.abs(sub.slice(i - 256, i).reduce((a, b) => a + b, 0) / 256);
  out[key] = { peak: +peak.toFixed(3), rms: +Math.sqrt(sum / d.length).toFixed(4),
               drift: +(drift / (sub.length - 256)).toFixed(5) };
}
out;
```

  Expected per key: `0.05 <= peak <= 0.9`, `rms >= 0.004`, `drift <= 0.01`.
